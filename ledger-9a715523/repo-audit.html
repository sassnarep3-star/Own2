Current repository irregularities

  • Root README says 180 unverified / 30 evidence records, while the current root checker reports different counts. Shared files are owned by another session; correction requested in coordination, not edited here.
  • Multiple historical board rows remain “in progress” despite later release logs. Later completion entries supersede them; this session does not rewrite another owner’s history.
  • Several subsites duplicate the same upstream inventory. Counts across sites must not be added together as distinct competitions.
  • Existing root and subsite validators are run during integration where compatible. This site’s own tests enforce its own evidence and link rules.
