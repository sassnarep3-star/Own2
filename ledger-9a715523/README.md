# PrizeLens

Independent, mobile-first competition research dashboard. This namespace preserves the existing root site and all earlier audit sessions.

## Run

```bash
python3 ledger-9a715523/tools/prepare.py   # re-import identities/source pointers from pinned snapshot
python3 ledger-9a715523/tools/build.py     # deterministic static HTML/CSV/JSON
python3 ledger-9a715523/tools/test.py      # coverage, evidence, local links, CSV, determinism
npm ci
node ledger-9a715523/tools/browser.cjs     # filters, saves, export, 320/390/1440px, axe, no-JS
python3 ledger-9a715523/tools/audit_links.py  # external reachability only; run where outbound web access is available
```

GitHub Pages serves committed HTML from `main:/`; the public path is `/Own2/ledger-9a715523/`.

## Data rules

- `data/inventory.json`: all 206 inherited identities, categories and source pointers; operational fields intentionally blank.
- `research/events.json`: 18 event-level reviews with field-specific official quotes, locators, URLs and flags.
- `research/link-audit.json`: dated network reachability report generated by CI. Reachability is not verification.
- `data/catalog.*`: generated combined catalog (224 records). Do not add counts from parallel subsites; they overlap.
- `EXECUTIVE_SUMMARY.md`: decision brief and limits.

No contest registration, payment, deposit, entry or prize claim is performed. Unknown values stay blank and appear in Flagged for Review. AI-themed rules are not treated as coding-agent authorship permission.
