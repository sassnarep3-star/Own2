Independent audit reports

These reports preserve separate, dated checks of selected competition leads. Each report links to its own official-source evidence and review flags; use the source page that matches the event before acting.

Coverage limit: these are independent spot audits, not one combined verification pass. Their row counts may overlap and must not be added together. None establishes current personal eligibility or guarantees a cash payout across the full 206-row source ledger. The main dashboard's unresolved entries remain on its Flagged for Review page.
Report dates and scope are copied from each report. Each row links one official source example; the full event-specific evidence and flags are in the linked report.

How to use these reports

Start with the event's official rules linked inside its report. A report's source link supports only the quoted field; it does not establish the competition is open, that the entrant qualifies, or that an advertised award is withdrawable cash. Recheck the live rules and event page before committing time.
