Method & rules

What this site claims, and what it does not.

Rules applied

  • Verified-or-blank. A prize, eligibility, entry-type, date or status cell is filled only if it was read on an official page during this review (2026-11-01). Otherwise it is blank and the row is marked Unverified.
  • Every row has a source link. Where the page was fetched, the link is the page that was read and carries a green checked badge. Otherwise the link is the source the original ledger tagged official (grey not re-checked); if the ledger tagged none, the row is marked no official source.
  • No inference. If a page did not state something (for example whether Kaggle entry is free), the cell is left blank even if it is commonly true.
  • Analysis is labelled. Rankings and AI-agent-fit comments are opinions, shown under an 'Analysis' label, separate from confirmed facts.

How pages were read

  • Live HTTP fetches of the official pages through a text-extraction fetcher. Pages that need JavaScript (Topcoder, Zindi) returned nothing and are recorded as unreachable.
  • Long pages are chunked; only the chunks listed in verified.json were read, and the page list for each entry states which.

Offline audit

tools/audit.js checks the original ledger for internal contradictions (URL form, source tiers, ended-vs-free, non-cash prizes tagged as USD, dates before 2026-11-01). Results are review prompts on the Flagged for Review page.

Not done

  • No entry was entered, and no account was created.
  • Eligibility for Texas residents was not confirmed for any entry beyond the 50-state wording on the CBS and NASCAR rules.
  • External link rot was not measured (see flagged page, section C).
